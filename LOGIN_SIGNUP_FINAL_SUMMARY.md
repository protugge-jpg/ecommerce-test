## 💻 Code Example

### Check if Logged In
```javascript
if (currentUser) {
    console.log("Welcome, " + currentUser.firstName);
} else {
    console.log("Please log in");
}
```

### Get User's Orders
```javascript
const orders = JSON.parse(localStorage.getItem('orders')) || [];
const myOrders = orders.filter(o => o.email === currentUser.email);
```
